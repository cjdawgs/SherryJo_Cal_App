Sync Management

Control the current data window, cadence, and refresh health without admin access.

Current Sync Range (days) Sets the rolling date window used for scheduled and manual syncs. This controls what is fetched from the provider, not what the calendar UI can display. Smaller values usually sync faster.
Frequency (minutes) Sets how often the background sync checks this account for updates. Default: 5 minutes.
Selected Account Chooses which connected account or accounts the settings and manual refresh actions apply to. Use All Accounts or Ctrl/Cmd+Click to multi-select individual entries.
Save Sync Settings Saves the selected range and cadence for the chosen account.
Manual Refresh Starts an immediate sync for the selected account using its configured date range.
Refresh Status Reloads the latest sync health, last run details, and scheduler timing.
