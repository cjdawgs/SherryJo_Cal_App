🔥 FireStick One-Time Sleep Fix

The app’s 5-layer anti-sleep engine delays sleep, but FireOS has a hidden system sleep timer (default 10–20 min) that no browser API can override. Run these ADB commands once per device to permanently disable it.

Step 1 — on the FireStick

Settings → My Fire TV → Developer Options
→ turn ON ADB Debugging
Settings → System → About → Network
→ note the IP address

Step 2 — on your laptop (adbLink / adb)

Connect to the FireStick IP, open ADB Shell, paste:

settings put system screen_off_timeout 2147460000
settings put secure sleep_timeout 0

These survive reboots. sleep_timeout 0 = disabled. screen_off_timeout 2147460000 ≈ 24 days (screensaver off).

Step 3 — on the Samsung TV

Settings → General → Anynet+ (HDMI-CEC) → Off
Stops the Samsung from signaling the FireStick to sleep when the TV remote goes idle.
